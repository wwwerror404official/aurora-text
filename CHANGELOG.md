# Changelog

## 1.5.0 — Public beta

- Package the existing 42 styles and two pickers for a public source repository.
- Add English/Russian UI localization and a language setting.
- Preserve existing style IDs, CSS classes and stored settings during migration.
- Add a deterministic Node build, pinned formatter, automated behavior/release checks and GitHub Actions.
- Include a self-contained browser demo, MIT license, privacy notes and a manual Obsidian verification checklist.
- Set a conservative public desktop baseline of Obsidian 1.14.5. Actual Obsidian compatibility and visual QA are pending.

This is a beta packaging/localization release. It does not claim a new wing repair, Live Preview per-letter support or Community directory approval.
